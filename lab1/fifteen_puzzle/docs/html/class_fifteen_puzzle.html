Подробное описание

Игра «Пятнашки» на квадратном поле.

Плитки хранятся числами 1..N*N-1, пустая клетка равна 0. Конструктор копирования, оператор = и деструктор не объявлены вручную: класс владеет только std::vector, поэтому копии, созданные компилятором, получаются глубокими и корректными.
