Подробное описание

Многочлен c0 + c1*x + c2*x^2 + ... + cn*x^n с вещественными коэффициентами.

Коэффициент при x^i хранится в элементе с номером i. Старшие нулевые коэффициенты отбрасываются, поэтому степень многочлена всегда настоящая, а нулевой многочлен имеет степень 0 и единственный коэффициент 0. Конструктор копирования, оператор = и деструктор не объявлены вручную: класс владеет только std::vector, поэтому копии, созданные компилятором, получаются глубокими и корректными. Сравнение коэффициентов точное (без допуска), как у обычных double.

Аргументы
degreeСтепень многочлена (не меньше 0).
coefficientsКоэффициенты от свободного члена к старшему, ровно degree + 1 штук.
Исключения
